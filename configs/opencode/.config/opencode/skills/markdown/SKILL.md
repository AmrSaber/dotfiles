## Guidelines
### Front Matter
Always create a front matter that contains:
- `description`: Describing what that md file is for
- `created-at`: The date at which this file was created
- `updated-at`: The date at which this file was updated

For dates in front matter, use format: "2026-06-21 12:30:50+00". Date is always in UTC format, and not the "+00" at the end to indicate UTC format.

## When to use me
- When asked to write/edit markdown files.
- Not to be used when reading markdown files.
- Do not actively update a markdown file you read just to add what's described here, unless asked by the user of course.
- IMPORTANT: NEVER USE FRONT MATTER WHEN WORKING WITH A README UNLESS ASKED BY THE USER
